# Komei Juku Argentina — Sitio Web

## Sobre el proyecto
Sitio web de Komei Juku Argentina, escuela de Iaijutsu tradicional japonesa (Muso Jikiden Eishin Ryu) bajo la dirección de Sekiguchi Takaaki Komei Sensei, 21° Soke.

## Stack
- HTML estático, CSS puro, JavaScript vanilla
- Sin frameworks ni bundlers
- Sin package.json — proyecto estático puro

## Estructura
- Páginas HTML en la raíz: index, sensei, cultura, dojos, galeria, katas, contacto, etc.
- `css/style.css` — estilos globales
- `js/main.js` — JavaScript global
- `img/` — imágenes del sitio
- `examen/` — sistema de examen
- `sql_tablas/` — tablas SQL del WordPress original

## Convenciones
- Idioma del sitio: español
- Nomenclatura CSS: BEM (`nav__link`, `nav__item--has-dropdown`)
- HTML semántico con atributos de accesibilidad (aria-label, etc.)

## Notas
- Respetar la estética japonesa tradicional y sobria del sitio
- Las referencias a la escuela, sensei y terminología marcial deben ser precisas
